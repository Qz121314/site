# 开发阶段与交付计划

当前只建设 `Qz121314/site`。目标是先完成中文后台的数据录入和管理，再完成英文用户前端。

实时客服、多语言和行业专属功能不在当前范围。

## 1. 开发原则

- 用户体验和操作路径先确定；
- 前端只使用 English；
- 后台只使用中文；
- 所有业务内容由后台录入；
- 分区创建后自动生成后台业务菜单；
- 产品和转化方式在所属分区内管理；
- 当前只部署一个正式 Worker；
- 所有删除功能支持选择、全选、批量删除、软删除、恢复和审计。

## 3. 阶段 1：单管理员认证与数据库基础

第一版不建立管理员账号体系。

Cloudflare Worker 手动绑定：

```text
ADMIN_PASSWORD
SESSION_SECRET
```

任务：

- [ ] 创建并绑定正式 D1；
- [ ] 建立 `sections` 初始表；
- [ ] 建立 `audit_logs` 初始表；
- [ ] 建立数据库迁移、备份和恢复脚本；
- [ ] 实现密码登录页；
- [ ] 实现 `POST /api/admin/auth/login`；
- [ ] 实现 `POST /api/admin/auth/logout`；
- [ ] 实现 `GET /api/admin/auth/session`；
- [ ] 使用签名 Cookie 保存短期会话；
- [ ] Cookie 使用 `HttpOnly`、`Secure`、`SameSite=Strict`；
- [ ] 限制登录尝试频率；
- [ ] 建立统一请求 ID 和错误格式；
- [ ] 后台写操作记录审计。

明确不做：

```text
admin_users
admin_sessions
角色与权限
密码哈希表
数据库密码重置
```

完成标准：

```text
管理员输入 Worker Secret 中配置的密码
→ 登录成功
→ 获得安全会话 Cookie
→ 可以访问后台 API
→ 修改 SESSION_SECRET 后旧会话全部失效
```
