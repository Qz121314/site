# 开发阶段与交付计划

当前只建设 `Qz121314/site`。目标是先完成中文后台的数据录入与管理，再完成 English 用户前端。

实时客服、多语言和行业专属功能不在当前范围。

## 1. 开发原则

- 用户体验和操作路径先确定；
- 用户前端只使用 English，后台只使用中文；
- 所有业务内容由后台录入；
- 分区创建后自动生成后台业务菜单；
- 产品和转化方式必须在所属分区内管理；
- 只部署一个正式 Worker、一个正式 D1 和一个正式 R2；
- 数据关系由外键、唯一约束和状态约束保护；
- 数据库结构只能通过顺序 migration 修改；
- 删除功能统一支持选择、当前页全选、批量删除、软删除、恢复和审计；
- 批量写操作必须支持幂等键；
- React 页面、API 路由和数据仓储保持职责分离。
