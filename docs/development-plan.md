## 阶段 5：转化池

每个分区有独立转化池。产品绑定转化分组，分组内绑定一个或多个同类型入口。

已完成：

- [x] 转化分组按分区隔离；
- [x] 分组类型为在线客服或外部链接；
- [x] 每个分组配置 CTA 按钮文字；
- [x] 每个分组绑定一个或多个客服/链接入口；
- [x] 入口启停、排序、选择、全选和批量删除；
- [x] 分组启停、排序、选择、全选和批量删除；
- [x] 分组和入口均支持模块内回收站恢复；
- [x] 顺序轮询游标与测试轮换；
- [x] 停用和回收站入口不参与轮换；
- [x] 分组已有入口时禁止修改分组类型；
- [x] 分组存在入口或产品引用时禁止删除；
- [x] 产品新增 conversion_group_id 关系；
- [x] 批量操作使用幂等键，所有写操作进入审计日志。

轮换模型：

```text
产品 CTA
→ 产品绑定的转化分组
→ 读取分组内启用入口
→ 按 sort_order 顺序循环选择
→ 在线客服：打开客服入口
→ 外部链接：跳转目标链接
```
