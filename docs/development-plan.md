# 开发阶段与交付计划

当前只建设 `Qz121314/site`。目标是先完成中文后台的数据录入和管理，再完成英文用户前端。

实时客服、多语言和行业专属功能不在当前范围。

## 1. 开发原则

- 用户体验和操作路径先确定；
- 前端只使用 English；
- 后台只使用中文；
- 所有业务内容由后台录入；
- 分区创建后自动生成后台业务菜单；
- 产品和转化方式在所属分区内管理；
- 当前只部署一个正式 Worker、一个正式 D1 和一个正式 R2；
- 数据关系由外键和约束保护；
- 数据库冻结后，表结构只能通过顺序 migration 修改；
- 所有删除功能支持选择、全选、批量删除、软删除、恢复和审计。
